Guided experiments

reproducible comparisons
01 / UPDATE TIME

What is learned before the outcome is known?

Single-step one episode with Monte Carlo, reset, then repeat with TD(0). Watch whether the value table changes before either terminal is reached.

02 / BACKUP LENGTH

Where is the bias-variance compromise?

On the 19-state chain, compare n=1, 4, and 10 with the same α. Track update delay, bootstrap magnitude, and RMSE variability over 100 episodes.

03 / TRACE DECAY

How far should one TD error travel?

Run TD(λ) with λ=0, 0.5, and 0.95. Single-step near a terminal and inspect how many earlier states retain meaningful eligibility.

  1. 01 / WAITMonte Carlo waits for a terminal outcome, then sends the observed return backward through the whole trajectory.
  2. 02 / BOOTSTRAPTD(0) updates immediately from one reward and the current estimate of the next state.
  3. 03 / HORIZONn-step TD chooses an explicit point between one-step bootstrapping and a complete sampled return.
  4. 04 / CREDITTD lambda combines many backup lengths through a decaying memory of recently visited states.
